// Features

搭載された 6つのモジュール

すべて単一のスクリプトに同梱。GUIからリアルタイムでON/OFFを切り替え可能です。

🤖

自動入力ループ

次の正解キーをDOMから解析し、keydown / keyup イベントを自動生成。0〜200msの範囲で入力間隔を自由に調整できます。

autoTypeConfig.delay
🛡️

God Mode

キー入力を常に正解コードへ書き換え、ミスカウントを強制リセット。エラー表示のCSSも同時に無効化します。

mistakeCount = 0
⛔

物理キーボード無効化

キャプチャフェーズでキーイベントを遮断。誤爆による記録汚染を完全に防止します。

stopImmediatePropagation
🔊

タイピング効果音

Web Audio APIによる矩形波シンセ。1200Hz→400Hzへ減衰する打鍵音をリアルタイム生成します。

OscillatorNode
📊

結果改ざん機能

得点・文字数・正解数・ミス数・正タイプ率をGUIから直接編集。結果画面への読み込み／反映をワンクリックで実行。

resultView_result
🖱️

ドラッグ可能GUI

グラデーション＋blurのパネルはヘッダーを掴んで自由に移動。最小化すれば☾ボタンとして待機します。

z-index: 99999

// Getting Started

使い方は 3ステップ

インストール不要。ブラウザの開発者コンソールに貼り付けるだけで起動します。

01

スクリプトをコピー

下部のコードボックスにある 「コピー」 ボタンを押すと、スクリプト全体がクリップボードに保存されます。

02

コンソールに貼り付け

対象ページで F12 → Console タブを開き、貼り付けて Enter。右上にGUIが出現します。

03

START をクリック

「自動入力 START」でエンジンが始動。必要に応じて God Mode や高速オートを活用してください。

// FAQ

    
よくある 質問

  

  

    

      
      
対象ページを開いた状態で F12（Macは Cmd+Option+J）を押し、Consoleタブにスクリプトを貼り付けてEnterキーを押すだけです。実行すると右上にグラデーションのパネルが出現します。ブックマークレットに登録しておくとさらに手軽です。

    

    

      
      
スクリプトはゲーム本体のエンジン初期化時にフックを仕込むため、ゲーム開始前に実行しておく必要があります。すでに始まっている場合は、ページをリロードしてからすぐに貼り付けてください。また、サイトの構造が更新されているとDOMセレクタ（#keyboard .key.next など）が一致せず動作しないことがあります。

    

    

      
      
この機能はすべてのキー入力を遮断します。解除はGUIのチェックを外すか、パネルの × でGUIごと閉じてください。GUIを消してしまった場合はページを再読み込みすれば元に戻ります。

    

    

      
      
ブラウザの autoplay ポリシーにより、AudioContext はユーザー操作の後でないと起動できません。「🔊 タイピング効果音」にチェックを入れたあと、STARTボタンなどを一度クリックしてください。内部で audioCtx.resume() が呼ばれます。

    

    

      
      
パネル右上の × ボタンでGUIは削除されます。ただしプロトタイプに施したフックはメモリ上に残るため、完全に元の状態へ戻すにはページの再読み込みが確実です。永続的な改変は一切行いません。

    

    

      
      
本スクリプトは完結したJavaScriptのみで構成されており、外部サーバーへの通信・ファイル書き込み・個人情報収集は一切行いません。コードは上記の通り全文公開されていますので、実行前に自分で中身を確認できます。

    

    

      
      
Chrome / Edge / Firefox / Safari の最新版で動作します（Web Audio API・CSS backdrop-filter を使用）。モバイルブラウザでは開発者コンソールが開けないため、PCでの利用を推奨します。
